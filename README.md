# Juan & Dara Gallery

A responsive blue & white liquid-glass photo gallery made for GitHub Pages.

## Deploy
1. Create a new GitHub repository.
2. Upload `index.html` and the `photos` folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, and choose `/ (root)`.
5. Save and wait for GitHub Pages to publish it.

All image paths are relative, so the gallery works on a GitHub Pages project URL.
